# 记餐

## 数据来源

营养数据优先级：

1. 用户给的。和食物库冲突时，先问用户。
2. 食物库。
3. 联网查（高可信源）：
   - 品牌食品（包装食品、连锁店产品）：先查品牌官网或电商商品页上的营养成分表；查不到，再到 FatSecret 中文站搜同品牌的这款产品。
   - 常规食材（鸡蛋、番茄、大米）：查中国食物成分表 `https://nlc.chinanutri.cn/fq/`。查不到，再到 FatSecret 中文站搜同品牌的这款产品。
   - 做好的菜（狮子头、番茄炒蛋）：到 FatSecret 中文站搜菜名 `https://www.fatsecret.cn/热量营养/search?q=菜名`。
4. 联网查（其他站点）：例如薄荷健康、小红书、公众号等。
5. 灵活估算或推算。

## 步骤

1. 对每样食物，在食物库里找到它。库里没有时按上面的顺序取营养数据，记录时用 `newFood` 新建。食物名只写食物本身（如「狮子头」、「盒马卤鸡腿」），是否估算只在回复里说明。

2. 对每样食物，确定规格：

   - 用户报了重量，按重量记。
   - 用户的说法能用库里的单位表示（如「一个」「半个」），按这个单位记（1 个、0.5 个）。
   - 用户说了大小（如「小的」「一大碗」），以标准换算为参照折算成克数，按克记，算估算项。库里的换算保持原样。
   - 库里没有这个单位的换算（如「个」），联网查它的标准重量，查到后用 `food_update` 补进库里；查不到就估算克数，只用于这次，算估算项。

   完成标准：每样食物都对应到一条食物和一个能换算的规格。

3. 按日期和餐别记录。以用户说的为准；没说时用今天和当前时间对应的餐别。

4. 用 `diet_query` 查这次记录的每一餐进行操作复核：列出食物的规格和热量、每餐合计，并标出所有估算项及依据。
